# Tổng Hợp Triển Khai Hệ Thống Dự Báo AQI Thời Gian Thực (Real-Time AQI Forecasting System)

- **Thời gian tổng hợp:** `2026-11-04 10:50 (+07:00)`
- **Trạm tham chiếu OpenAQ v3:** Số 1 đường Giải Phóng - phường Bạch Mai - ĐHBK (`OPENAQ_LOCATION_ID=4946813`, tọa độ `21.0056°N, 105.8433°E`)
- **Mục tiêu:** Đưa 9 mô hình học máy & học sâu (`t+1` và `t+6`) từ giai đoạn huấn luyện offline lên vận hành thời gian thực end-to-end (Data Ingestion → Persistent Storage & CSV Archiving → Rolling Inference → REST API → React Dashboard & Live Evaluation).

## 4. Các Câu Lệnh Vận Hành Nhanh (Quick Commands)

- **Khởi chạy toàn bộ hệ thống (Backend + Web Dashboard):**
  ```bash
  ./run_realtime.sh
  ```
  *(Mở trình duyệt tại `http://localhost:5173`)*

- **Tải bù / cập nhật dữ liệu lịch sử OpenAQ ĐHBK về file CSV (ví dụ 7 ngày gần nhất):**
  ```bash
  .venv/bin/python scripts/collect_openaq_dataset.py --days 7
  ```

- **Chạy kiểm chứng thực nghiệm & vẽ lại biểu đồ Dự báo vs. Thực tế OpenAQ:**
  ```bash
  .venv/bin/python scripts/evaluate_openaq_live.py
  ```

- **Chạy bộ kiểm thử tự động (Unit Tests):**
  ```bash
  .venv/bin/pytest tests/ -q
  ```
